Begin with Tutorial 0 · decision models and creative controls. It explains what each demo means and why we author allowed choices.

Open Workflows → GeneretiCore → 01 - Read a decision - no model, then press the blue Run button at the top of Comfy. Read the two result nodes on the right. This first example needs no model.

Refresh the Workflows panel if it was already open. Eight samples are installed when Comfy starts; edited copies are preserved.

Try these in order

  1. 01 - Read a decision - no model: Run, read the label/JSON, edit the example scores, set choice to the largest score, Run again.
  2. 02 - Local text: download Qwen 0.6B if missing; Run for an artwork title. Edit the prompt and repeat.
  3. 03 - Local decisions: use the same model; Run to choose a palette from a fixed list. Read the scores.
  4. 04 - Local vision: download Qwen3-VL 2B (about 3.3 GB) if missing; Run to describe a blue fixture. Replace Empty Image with Load Image to analyze your own picture locally.
  5. 05 - Genereti - sketch to vision walkthrough: watch the p5 circle, then top Run to analyze one frame. The sketch keeps moving while local AI works.
  6. 06 - Genereti - AI palette walkthrough: watch the sketch, then top Run. Choice → hue mapping → moving artwork. Edit the prompt and compare.
  7. 07 - d1 - scene to artwork palette: d1 reads a situation and question, chooses blue/orange, and drives the authored circle through a numeric mapping. Change the situation, keep the options fixed, and inspect the Tree / Pretty / Minified result viewer.

Samples 05/06/07 require the separate Genereti public pack. Scroll below their graph and press Run on walkthrough for guided steps. Samples 00–04 only need GeneretiCore and standard Comfy nodes.

What to expect

Completed text/JSON appears inside the inference node and, after workflow Run, in the connected result nodes. Timing details show how long the local request took. An independent preview is labeled preview; a queued result is labeled workflow complete.

The small Qwen starter gave wrong answers and poor palette choices in tests. These samples teach wiring; they do not guarantee good decisions. Scores are uncalibrated. Only labels and numbers drive the palette example; no generated code executes.

If you're stuck

  • No workflows: restart Comfy, refresh Workflows, or drag JSON from example_workflows/ into Comfy.
  • Model missing: click ↓. Text/decisions share Qwen 0.6B; vision uses its own model.
  • Blank connected preview: press top Run, not ϟ.
  • Missing Genereti nodes in 05/06/07: install Genereti public in this Comfy instance and restart.
  • Helper missing: Qwen requires macOS 27+; d1 Core ML requires macOS 15+ Apple silicon. Build d1 with python3 scripts/build_d1_helper.py. Build Qwen with python3 scripts/build_helper.py.

No inference, camera, microphone or audio starts just by opening a workflow. Model inference stays local.
