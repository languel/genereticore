Every four pieces, a separate decision chooses calm, drive, tense or celebrate. The next pattern takes over at the next bar; no generated code runs.

What is authored, and what does d1 decide?

The game rules, candidate shortlist, colors, sounds and patterns are authored. d1 ranks labels. Candidate features expose holes, cleared rows and board height; a higher score is not proof of a better move. Use the heuristic player as a no-model comparison. Errors pause the game; there is no automatic fallback. Rendering and audio continue independently of inference. Pause/Reset invalidates outstanding results.

This is a simplified hard-drop simulation: no player controls, hold, wall kicks, or competitive scoring. Music uses local Web Audio oscillators, not Strudel or downloaded samples.
