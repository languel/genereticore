# Welcome to ꘅ GeneretiCore

GeneretiCore adds local inference to Genereti’s creative surfaces. Rendering, editing, preview display and inference are separate activities. Opening Help or a workflow does not download models or start inference.

## Inputs, outputs and controls

Use the header ? for this shared Reference, Contents and Assistant panel when Genereti is installed. Ask about this node prepares context and a draft; you choose when to send. Without Genereti, ? opens the local reference.

## Small example

Start with **01 - Read a decision - no model**. Run the supplied validator fixture and inspect its JSON. Then read Tutorial 0 and choose a model-backed example.

## Requirements and limits

Core AI text/vision/Qwen decisions require macOS 27+ Apple silicon and the contributor Swift helper. Text-only d1 requires macOS 15+ Apple silicon and its separate helper. SDXS and SD Turbo require macOS 14+ Apple silicon, optional image-runtime dependencies and existing converted packages. Linux can inspect docs and validate example graphs; it cannot run these Apple backends. No automatic cloud fallback. These are experimental contributor paths, not a verified student distribution.
